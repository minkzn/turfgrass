## Accuracy / source rules
- Correct answers are exact phrases extracted from uploaded course PDFs or assigned textbook pages.
- Every question reveals its source after submission.
- The same exact keyed answer appears no more than 2 times within any one module bank.
- M6 Overview cites a 9th-edition Chapter 8 page set not included in the upload; M6 quiz/study content therefore uses the uploaded M6 course PDFs only.
- No outside knowledge is used.

## Quiz behavior
- 10 questions per batch
- correct answers retire
- missed answers cycle to the back
- progress saved per module filter in localStorage
